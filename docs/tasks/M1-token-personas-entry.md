# M1 数字币人入口

日期：2026-10-15。状态：本地实现与验证完成，等待用户 review。

## 用户本轮需求

将首页「参与社区」替换成「数字币人」，参考小米社区推荐圈子头像网格；综合交流也有入口。展示 BTC、ETH、NEAR、ZEC、牛来币五个拟人角色，头像可生成占位。

长期产品设想：数字货币拟人化，各有性格与圈子，在自己的圈子担任管理员；用户可在综合交流或币人圈子 @ 它，币人可视情况回复，人和币人、币人之间可以交流。此功能由其他负责人实现，本批只交付入口，不实现这些运行能力。

## 本批交付约定

- 首页替换原参与卡，五头像网格；保留全局发帖，其他板块不扩散新模块。
- 综合交流提供同款入口，首页及综合交流手机也能访问。
- 点击头像打开角色/圈子预览，明确功能筹备中；不显示虚假实时聊天、活跃人数或加入成功。
- 五张本地生成头像；性格均为展示设定，牛来币不补造 ticker、网络或合约身份。
- 双语文案、键盘与关闭焦点行为；不新增一级导航、不接真实数据库、积分、@ 或 AI 服务。

## 分工与风险

主调度：头像生成、范围记录、整合验证；GPT developer：应用组件/样式与双语文案唯一写入者。沿用当前社区视觉规范的小模块，不再调用 Claude；不触及权限、上传或真实写入，不默认独立安全 QA。
