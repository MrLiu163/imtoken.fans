# M1-A 品牌首页与导航：开发及 review 任务卡

状态：**M1-A 已实现，等待用户 review**。用户于 2026-10-15 已授权开始。验收与限制见 [review 记录](../reviews/M1-A-home.md)。  
目标：用户能从 imToken Fans 首页看懂四板块，并找到安全指南、反馈、讨论与活动入口。

## 第一批范围

先做首页与导航的内容/设计方案，整合后实现可预览页面；缺少的新路由不能包装为已实现。
首页建议沿用玫红/深蓝/白底 Logo 基调；保留中英、移动端及旧内容入口。
登录、About、规则、FAQ、图标等后续 M1 子任务在首批设计约定后拆卡，避免一次改全站。

## 建议调度

1. 总调度盘点并填 [设计 Brief](../design/brief-template.md)，限定首批首页/导航与实际功能边界。
2. 通过 Devin 自动调用 Claude Opus 5.5，输出最多两个设计方向与交互规范；集中收集用户反馈。
3. 以 Claude 推荐方向作为可评审首稿，GPT developer 实现；同时负责中英文案、前后端契约和不重叠文件。
4. 普通视觉改动由 developer 自检，无需单独 QA；若实际涉及身份、权限、媒体、迁移或重大流程，独立 qa 按风险介入。
5. 总调度核验并更新进度，报告未实现路径与环境限制。本批完成后暂停后续重要阶段，等待用户 review。

## 预期验收

- 展示正确品牌与四个一级板块，AI 共创归入产品反馈；旧 AI 内容能追溯。
- 主行动及各入口指向真实可用路径；不伪造活动、版本记录、数据或官方承诺。
- 文案两份 JSON 一致，无新增硬编码界面文字；移动端可访问导航和操作。
- 相关 i18n/lint/build 与实际桌面/移动端预览结果有记录；缺环境标为未验证。

## 本批角色与文件归属

- 总调度：Brief、管理文档、数据库只读核对、整合检查、浏览器预览、review 汇总。
- Claude designer：已交付 [设计规范](../design/M1-design-v1.md)，推荐“白底社区指南”；本批不追加无必要设计轮次。
- GPT developer：页面/导航/品牌组件、双语 messages、全局样式、启动配置与本地说明，统一负责前后端。
- 风险 QA：仅核实安装时已发现的依赖安全告警及修复验收，不对每处文案/样式额外审计。

共享代码和两份 messages 由 developer 单一写入，主调度不同时修改。

固定 localhost:3000；原生埋点属于已有页面行为，不在本批重构。新业务功能与数据迁移另立阶段。
