# M1 首页图片、提示清理与聚合排序

日期：2026-10-15。状态：本地交付与验证完成，等待用户review。

## 用户要求

1. 首页 banner 使用几张美观图片。
2. 排查社区重复的示例/虚构提示，删除顶部演示条、列表尾长提示等冗余信息；上线前再清空假数据。
3. 首页推荐、最新、热门聚合所有论坛板块：管理员推荐标签、发布时间、评论最多。

## 本批口径

- 三张本地AI生成横幅，分别服务安全案例、交流活动和社区作品，实际文案仍用双语HTML，图片不写字。
- 移除浏览页重复演示标签，单一低调页脚保留「预览版本」；发布预览仍说明未发布，评论等完成后以简短状态说明本地生效；不删作品不存在、非官方公告、活动未开放等必要事实，不伪造业务完成。
- 推荐严格筛选管理员推荐标记，再按发布时间倒序；最新所有记录按发布时间倒序；热门按评论数倒序，同数按发布时间倒序。
- 首页聚合四板块；板块内同排序限定本板块；顶部热门和详情热门统一评论数口径。轮播曝光不影响推荐排序。
- 评论数量由实际本地种子评论计算，列表与详情初始一致；新增本地评论更新当前详情，不要求跨页持久化。
- 当前未接真实内容模型或后台推荐写入；本批 `featured` 是管理员推荐语义的本地字段，不能宣称正式管理员已操作或真实全库聚合完成。

## 分工/风险

主调度负责图像生成、范围文档和浏览器验证，GPT developer唯一写应用、样式与双语messages。沿用视觉规范，不再调用Claude。无数据库、权限或媒体上传变更，不默认独立QA。
