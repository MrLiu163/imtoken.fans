# 小米社区参考观察

2026-10-15，主调度使用ego-browser实际只读打开 [小米社区](https://www.xiaomi.cn/)，页面标题“小米社区”，观察到以下内容结构；用户另提供首页与详情截图作视觉参考。

- 紧凑顶栏提供首页/圈子等导航、搜索入口与登录。
- 首页左侧连续帖子流，右侧资讯、更多功能与推荐圈子；主体直接呈现内容，不以长篇网站介绍开场。
- 帖子突出作者、成长等级、正文摘要、图像/视频、时间、评论与点赞。
- 用户给出的详情参考显示正文和评论主栏，右侧为作者、热门帖子等辅助信息。
