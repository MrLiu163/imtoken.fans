# imToken Fans 首页精简方案（推荐方案 · 唯一）

## 1. 结论
首页只保留三件事：**推荐轮播 + 热门榜**、**统一内容流**、**紧凑侧栏**。四个板块的入口只放在顶部导航。删除欢迎语、四张入口卡片、四板块筛选、成长大卡和重复公告。整体用白底、玫红点缀、深蓝文字，参考小米社区的布局，但不使用它的黑色主题。

## 2. 命名（必需）
| 一级导航 | EN | 二级分类 |
|---|---|---|
| 钱包安全 | Wallet Security | 故事 Stories / 案例 Cases / 指南 Guides / 问答 Q&A |
| 产品共创 | Co-create | 产品反馈 Feedback / 社区产品 Community Builds / 产品公告 Updates |
| 综合交流 | Discussion | 论坛 Forum |
| 活动 | Events | — |

一级导航不再叫“产品反馈”。“社区产品”不限于 AI。

## 3. 桌面结构
- 内容区最大宽度 **1200px**，居中，两侧留白，页面不再铺满宽屏。
- 主栏占 **8/12**（约 790px），侧栏占 **4/12**（约 380px），栏间距 24px。
- 页面从上到下依次是：
  1. 导航
  2. 演示提示条（保留，高 36px）
  3. 推荐区：左边轮播，右边“热门”
  4. 主区：左边内容流，右边侧栏
- 推荐区高度 **320px**；轮播与热门的宽度和主区两栏对齐。

## 4. 轮播（最多 3 张，均为示例）
- 3 张分别是：安全案例、活动、社区产品，点击后进入已有详情页。
- **视觉**：纯色底，用浅玫红、浅深蓝、浅灰轮换，加一个现有线性图标。左下角依次放：分类标签、标题（24/32 半粗）、一行摘要、“示例”角标。不用营销口号、倒计时、奖励或报名承诺。
- **交互**：
  - 有上一张/下一张按钮（40px 圆形，悬停或聚焦时显示，移动端常显）。
  - 有指示点（8px，当前项拉长为 24px 玫红，点击区域 ≥24px）。
  - 键盘：Tab 聚焦后可用 ←/→ 切换。
  - 自动播放间隔 6s，并带暂停/播放按钮；悬停、聚焦或页面隐藏时暂停。
  - 开启 `prefers-reduced-motion` 时关闭自动播放，切换改为淡入（≤150ms）。
- **无障碍**：容器标注为轮播区域并写明“第 n / 3 张”；非当前张不可通过键盘聚焦。
- **状态**：
  - 加载：同尺寸骨架块。
  - 失败或空：隐藏轮播，热门榜扩展为整行，不显示报错大块。
  - 只有 1 张时：不显示切换控件。

## 5. 热门榜
- 标题“热门 Hot”，右侧放“换一批”（本地切换）。
- 显示 6 条：序号（前 3 名玫红）+ 单行标题省略，行高 44px。
- 不显示作者和数据。热门榜与内容流的“热门”排序是同一份数据的不同视图。

## 6. 内容流
- 顶部只有一组排序：推荐 / 最新 / 热门，右侧显示“共 12 篇示例”。
- 每条的组成：
  - 作者行：头像 24px、昵称、等级、“· 板块 › 分类”
  - 标题：18/26 半粗，最多 2 行
  - 摘要：14/22 灰色，1 行
  - 元信息：日期、评论、赞，靠右显示“演示帖”
- 缩略图可选，88×88px 放右侧，没有真实图片时不渲染，不用占位插画。
- 每条约 120px，条目之间用 1px 分隔线，不做卡片堆叠。首屏可见 4–5 条。
- **状态**：
  - 加载：3 条骨架。
  - 空：“暂无内容”+ 发帖按钮。
  - 失败：“加载失败”+ 重试。
  - 未登录点互动：弹出轻提示“演示环境，互动仅保存在本地”。

## 7. 精简侧栏（顶部吸附，top 80px）
1. **参与**：一张卡片，放“发帖”主按钮和“去签到”文字链。成长信息只保留一行“Lv2 · 760 XP（示例）”。
2. **安全提醒**：一张卡片，3 条短句，比如“不要泄露助记词”“官方不会主动私信”，加“查看指南 ›”。

侧栏不重列导航，不放热门（推荐区已经有），也不放公告。

## 8. 移动端（<768px）
- 导航收起为 Logo + 汉堡菜单 + 发帖图标，四个板块放在菜单里。
- 顺序：演示条 → 轮播（比例 16:9，左右各 16px，按钮常显）→ 排序 tabs → 内容流。
- 热门榜收到“热门”tab 里，不单独占一块。
- 安全提醒放到第 4 条之后，作为一张内联卡片插入一次。
- 参与入口用右下角发帖按钮（56px），并避开底部安全区，不遮挡内容。
- 768–1023px：使用单栏，侧栏内容移到内容流顶部，并排成一行两项。

## 9. 样式参数
- **颜色**：主色玫红 #E0386A，悬停 #C42A5A；深蓝文字 #14213D，次级文字 #5B6478，辅助 #8A93A6；分隔线 #EDEFF3；页面底 #F6F7F9；卡片 #FFF。
- **字体**：PingFang SC / Noto Sans SC，英文用 Inter；正文 15/24，英文保持 1.5 行高。
- **间距**：8pt 网格，模块间距 24px，卡片内边距 20px（移动端 16px）。
- **形状**：圆角 12px（按钮 999px）；不用阴影或只用 0 1px 2px rgba(20,33,61,.06)；不用玻璃、渐变或霓虹效果。
- **可访问性**：对比度 ≥4.5:1；焦点环 2px 玫红，偏移 2px；触控目标 ≥44px。

## 10. 模块数量
- **必需（最少 3 个）**：推荐区（轮播 + 热门）、内容流、安全提醒。
- **可删**：热门榜（并入 tab）、参与卡（改用全局发帖按钮）、缩略图、自动播放。
- **待决策**：顶部是否加搜索框（目前没有后端检索，只能做本地标题过滤）；演示条是否可以关闭。

## 11. 风险与说明
- 所有推荐和数据都是示例，互动只保存在本地；不出现官方身份、产品版本或奖励承诺。
- 这份方案只做了设计，没有写代码，也没有在页面上验证。实现后需要检查两点：轮播的键盘和读屏是否正常，中英文切换时标题是否溢出。
