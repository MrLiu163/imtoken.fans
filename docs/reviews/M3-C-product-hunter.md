# Product Hunter 首版 review

2026-10-15。本地开发分支 `feature/product-hunter` 可预览。

## 已交付

- 提交产品：产品专属表单、Logo/截图、网址、平台、价格、阶段、创作者关系、创作者说明和反馈诉求；本机自动保存草稿；链接去重后进入现有审核流程。
- 发现产品：最新发布、近期热门、社区高分排序；关键词、平台、价格、阶段、类别筛选；评分、支持和评论指标独立显示。
- 产品评分：支持票可取消；确认真实体验的非作者用户可提交或编辑 1–5 星评价、正文及优缺点标签；社区高分至少需要 5 条评分。
- 产品详情继续复用现有评论体系，产品主路径不再展示旧愿付费/创意票或模拟投资。
- 页面视觉沿用现有社区的白底、深蓝、玫红、圆角面板和响应式排版；中英文同步。

## 数据与安全

迁移文件为 `supabase/migrations/0023_product_hunter.sql`。产品支持和评分均有数据库唯一约束及 RLS；只有已发布产品可互动；评分要求登录、体验确认且禁止作者自评。产品审核沿用现有 moderation pipeline，待审内容不会进入公开列表。

本机仓库没有 Supabase 凭证，因此迁移未执行，页面当前以真实空状态展示，未伪造产品数据。真实提交、审核、支持、评分、并发重试和角色权限仍需连接目标 Supabase 后验收。
